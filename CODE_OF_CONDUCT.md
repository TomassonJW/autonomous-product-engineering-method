# Code of Conduct

This project uses a simple conduct standard: be precise, respectful, and useful.

## Expected Behavior

- Challenge ideas without attacking people.
- Keep discussions grounded in evidence, examples, and tradeoffs.
- Respect safety boundaries around credentials, private data, external systems, and publication.
- Make room for both beginner and expert perspectives.
- Prefer clear correction over performative debate.

## Unacceptable Behavior

- Harassment or discriminatory language.
- Publishing secrets, personal data, or private operational details.
- Encouraging unsafe automation or bypassing explicit approval gates.
- Presenting speculation as proven fact.
- Repeatedly derailing technical review with vague claims.

## Reporting

For security-sensitive issues, use [SECURITY.md](SECURITY.md). For conduct concerns, open a private maintainer channel if available. If no private channel exists, avoid posting sensitive personal details in public issues.
