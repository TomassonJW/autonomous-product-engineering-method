# Manifesto

Software built with autonomous agents should not become faster nonsense.

The point is not to generate more screens, more files, more routes, more tasks, or more confident summaries. The point is to transform human intent into useful, safe, maintainable software with visible tradeoffs.

## The User Can Speak Normally

The user should not need to say:

> "Create a modular, event-driven, cost-governed, dual-plane agentic system with observability and bounded worker autonomy."

They may say:

> "I want the system to do the whole thing, not a toy version."

The method exists to translate the second sentence into the first kind of engineering structure, without losing the user's actual ambition.

## Challenge Is Care

An agent that only obeys can build the wrong thing quickly.

Challenge is not obstruction. It is a protection against:

- false scope;
- hidden cost;
- fake premium UX;
- shallow demos;
- unsafe autonomy;
- untestable architecture;
- public claims without proof.

## Premium Is Behavioral

Premium is not a visual skin. It is the behavior of a system that respects the user's attention, trust, money, data, and time.

A premium system:

- tells the truth;
- makes the main action obvious;
- hides complexity until needed;
- exposes enough control for advanced users;
- fails clearly;
- avoids surprising costs;
- preserves reversibility where possible;
- earns confidence through evidence.

## Autonomy Needs Governance

An autonomous worker without boundaries is not a product capability. It is an unmanaged process.

Every worker needs:

- a mission;
- a queue;
- a boundary;
- a budget;
- checkpoints;
- logs;
- status truth;
- stop conditions;
- quality gates;
- a final report that can be rejected.

## The Goal

The goal is a reusable method that helps humans and agents build the right depth of product:

- not a tiny tool when the ambition is a platform;
- not a massive platform when the need is a simple action;
- not a beautiful shell without working journeys;
- not a powerful system that only experts can tolerate.
