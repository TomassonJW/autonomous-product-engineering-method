# Start A New Product With The Method

## Purpose

Start from ordinary language and create the first structured product artifacts.

## When To Use

Use when a user has an idea but no formal product brief.

## Expected Output

Product brief, profiling notes, challenge depth, and first useful slice.

## Prompt

```text
I want to describe a product in ordinary language.

Use the Autonomous Product Engineering Method.

Do not ask generic intake questions first. Deduce what you can, mark assumptions, and ask only questions that change the product direction, UX, architecture, safety, or cost.

My product idea:
<paste ordinary-language idea here>

Produce:
1. Reformulated intent.
2. Product profile.
3. Ambition level.
4. Ambiguity map.
5. Decisive questions.
6. Challenge level.
7. First useful slice.
8. Suggested next artifact.

Constraints:
- Keep language clear.
- Do not start coding.
- Do not pretend the idea is fully specified.
- Do not overbuild or underbuild without explaining the tradeoff.

Safety boundaries:
- No secrets.
- No external actions.
- Red actions require explicit approval.

Next step:
Tell me whether we should create a product brief, challenge report, or capability map first.
```
