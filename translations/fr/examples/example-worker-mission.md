# Exemple de mission worker

## Mission

Créer le premier scaffold documentaire pour un dépôt public de méthode d'ingénierie produit.

## Scope autorisé

- Documentation Markdown.
- Templates.
- Prompts.
- Exemples publics sûrs.
- Commits Git locaux.

## Hors scope

- Lire des secrets.
- Publier avant scan de secrets.
- Ajouter un runtime de code.
- Affirmer que la méthode est finale.

## Zone de sécurité

Verte pour création locale de fichiers et commits.

Rouge pour publication GitHub publique, autorisée seulement après scan public-safe et demande explicite de l'utilisateur.

## Checkpoints

1. Scaffold créé.
2. Docs cœur rédigées.
3. Bibliothèque de prompts et templates ajoutée.
4. Audits terminés.
5. Scan secret passé.
6. Décision de push prise.

## Rapport final

Doit inclure chemin, statut Git, commits, checks, limites, risques et prochaines améliorations.
