# Statut de traduction française

Statuts autorisés :

- `translated` : traduction française présente et alignée avec la source connue.
- `partial` : traduction présente mais volontairement incomplète.
- `missing` : traduction absente.
- `fr-sync-needed` : la source anglaise a changé ou doit être revue côté français.
