# Example Product Intake

## Raw User Statement

> I want a tool that builds apps for me. It should feel premium, not like a toy. I want simple controls, but I also want deep settings when I need them.

## Reformulated Intent

The user wants an AI-assisted app-building product that accepts ordinary-language goals, turns them into product and engineering plans, and can execute bounded development work while keeping the main user experience simple and expert controls available.

## Ambition Level

Likely: **Autonomous system**.

Possible lower interpretation: prototype generator.

Possible higher interpretation: full autonomous software factory.

## Decisive Questions

1. Should the system generate only plans and code patches, or should it also create pull requests and run workers?
2. Is the first user a non-technical founder, a developer, or both through separate UI planes?
3. What actions are allowed without approval?

## First Useful Slice

Create a local workflow that converts a product idea into a product brief, challenge report, capability map, and Codex build plan.
