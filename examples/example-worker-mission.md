# Example Worker Mission

## Mission

Create the first documentation scaffold for a public product-engineering method repository.

## Allowed Scope

- Markdown documentation.
- Templates.
- Prompts.
- Public-safe examples.
- Local Git commits.

## Out Of Scope

- Reading secrets.
- Publishing before secret scan.
- Adding code runtime.
- Claiming the method is final.

## Safety Zone

Green for local file creation and commits.

Red for public GitHub publication, allowed only after public-safety scan and explicit user request.

## Checkpoints

1. Scaffold created.
2. Core docs written.
3. Prompt and template library added.
4. Audits completed.
5. Secret scan passed.
6. Push decision made.

## Final Report

Must include path, Git status, commits, checks, limits, risks, and next improvements.
