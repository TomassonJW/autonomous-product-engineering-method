# Example Challenge Report

## Request

> Build software that generates 3D games.

## What This Could Mean

- a demo generator;
- a playable prototype tool;
- a level editor;
- an asset pipeline;
- a game engine extension;
- an autonomous game studio;
- a full game production operating system.

## Challenge Level

Structured.

The phrase spans several ambition levels.

## Main Risks

- Building a small 3D toy when the user expects a production pipeline.
- Starting architecture before deciding whether this is a tool, engine, studio, or platform.
- Hiding asset, physics, testing, and performance costs.
- Designing one UI that mixes player, creator, and operator workflows.

## Recommended Scope

Start with a product profiler and a prototype generator slice:

1. User describes game idea.
2. System creates a game concept brief.
3. System maps required assets, mechanics, levels, and risks.
4. System generates a small playable prototype plan, not a full engine.

## Must Not Happen Without Approval

- claiming full game generation;
- publishing generated games;
- buying assets or API services;
- using copyrighted material;
- running unbounded generation loops.
